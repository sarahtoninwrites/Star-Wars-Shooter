# Star-Wars-Shooter
A Star-Wars-themed mobile-optimized 2D shooter game built entirely using C# in Unity. The player can drive the Millennium Falcon through space, battling Tie Fighters!

Featuring:
- 👾 Random enemy spawns
- 💥 Bullet shooting mechanics (player + enemy)
- 🎵 Background music with mute/unmute controls
- 🛡️ Collision-based damage
- 🔫 Object pooling for smooth performance

## 📱 Platform
- Android (Built and tested)
- Unity Editor Version: 6000.0.26f1

## Want to give it a play? 
- Download the .apk file from this google drive [https://drive.google.com/file/d/1DFEI7AT4EZa3-LSEkl07AwiR7ucSN1NJ/view?usp=sharing] onto your Android phone, and follow package manager instructions to install the app
- Play!
